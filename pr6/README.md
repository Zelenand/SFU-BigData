# Лабораторная работа 6
Самарин НА КИ25-04-3М

Консольное приложение на PySpark.Добавляет Kafka + Spark Structured Streaming из ЛР6.

## 1. Структура проекта

```text
LR6/
├── main.py
├── requirements.txt
├── docker-compose.yml
├── README.md
└── data/
    ├── orders_clean/
    ├── order_items_clean/
    ├── products_clean/
    ├── customers_clean/
    ├── reviews_clean/
    └── output/
```

## 2. Подготовка данных

Скопируйте очищенные Parquet-данные из ЛР3 в папку `data`. Приложение ожидает папки:

- `orders_clean`
- `order_items_clean`
- `products_clean`
- `customers_clean`
- `reviews_clean`

## 3. Установка

Требуется Python и Java, совместимая с установленной версией Spark. В терминале из папки проекта выполните:

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Установка библиотек:
```bash
pip install -r requirements.txt
```

Kafka-коннектор Spark загружается через Maven при первом запуске. Для Spark 4.x приложение использует Scala 2.13, для Spark 3.x — Scala 2.12.

## 4. Запуск Kafka

Установите и запустите Docker Desktop, затем в папке проекта выполните:

```bash
docker compose up -d
```

Kafka будет доступна приложению по адресу `localhost:9092`.

Проверить контейнер:
```bash
docker compose ps
```

Остановить Kafka:
```bash
docker compose down
```

Для полного удаления данных Kafka:
```bash
docker compose down -v
```

## 5. Запуск приложения

```bash
python main.py
```

При запуске приложение читает очищенные Parquet-таблицы из `data`.

## 6. Пункты меню

| Пункт | Возможность |
|---|---|
| 1 | Просмотр загруженных данных |
| 2 | Анализ продаж по месяцам |
| 3 | Анализ продаж по категориям |
| 4 | Анализ заказов по регионам |
| 5 | MapReduce: частотность слов в отзывах |
| 6 | Экспорт аналитических результатов в CSV и Parquet |
| 7 | Обучение Logistic Regression для тональности отзывов |

| 9 | Kafka Producer: отправка заказов в топик `olist-orders` |
| 10 | Spark Structured Streaming: чтение Kafka, фильтрация и агрегация по минутным окнам |
| 11 | Просмотр сохранённых результатов потоковой обработки |

## 7. Как выполнить потоковую обработку

1. Запустите Kafka через `docker compose up -d`.
2. Запустите приложение: `python main.py`.
3. Выберите пункт **9**. Введите число событий или нажмите Enter для отправки всех заказов.
4. После завершения Producer выберите пункт **10**. Приложение начнёт читать события из Kafka.
5. Остановите обработку сочетанием `Ctrl+C`.
6. Выберите пункт **11**, чтобы посмотреть сохранённые результаты.

Результаты потоковой обработки сохраняются в `data/output/kafka_streaming`, контрольные данные Spark — в `data/output/kafka_checkpoint`.

Важно: для потоковой агрегации используются минутные окна и watermark 2 минуты. Kafka-события содержат идентификатор заказа, время заказа, сумму заказа и количество товарных позиций. Некорректные и пустые события отбрасываются.
