# Проект по аналитике больших данных в сфере электронной коммерции

## Общая характеристика проекта

В рамках проекта предполагается разработка аналитической системы обработки и анализа больших данных для интернет-магазина. Основное назначение системы — сбор, хранение, обработка и анализ информации о заказах, покупателях, товарах и отзывах с целью выявления закономерностей потребительского поведения, исследования динамики продаж, оценки удовлетворённости покупателей и прогнозирования спроса.

Актуальность проекта обусловлена постоянным увеличением объёмов информации, формируемой в процессе работы интернет-магазинов. Данные поступают из различных источников, отличаются по структуре и форматам хранения, поэтому для их эффективного использования необходимы специализированные средства интеграции, распределённого хранения и обработки.

Проект также имеет определённую связь с тематикой магистерской диссертации, посвящённой интеграции данных из гетерогенных источников. В частности, в разрабатываемой системе предполагается объединение структурированных и неструктурированных данных, поступающих из различных источников и представленных в разных форматах. Однако основное внимание проекта будет уделено не самой интеграции, а последующей аналитической обработке полученной информации с использованием технологий больших данных.

## а) Источники данных, хранилища и технологии хранения

В качестве основных источников информации предполагается использовать следующие категории данных:

1. Данные о заказах: идентификаторы заказов, даты оформления, статусы выполнения, даты доставки и отмены заказов.
2. Данные о покупателях: идентификаторы клиентов, географическое расположение, история покупок.
3. Данные о товарах: наименования, категории, характеристики и стоимость товаров.
4. Данные о продавцах: идентификаторы продавцов, местоположение и сведения о реализуемых товарах.
5. Данные о платежах: способы оплаты, суммы платежей и количество платежей в рамках заказа.
6. Данные об отзывах: оценки покупателей и текстовые комментарии о приобретённых товарах и качестве обслуживания.
7. Внешние данные: географическая и региональная информация, а также дополнительные сведения, которые могут влиять на потребительский спрос.

Основным источником данных станет открытый набор Brazilian E-Commerce Public Dataset by Olist. Он представлен несколькими файлами CSV, что позволяет использовать его для исследования различных аспектов деятельности интернет-магазина.

Для расширения возможностей системы также предусматривается использование JSON-файлов и текстовых данных. В дальнейшем может быть реализовано подключение PostgreSQL в качестве реляционной базы данных для хранения структурированной информации, а также Kafka для приёма потоковых событий.

Для хранения данных предполагается использовать несколько технологий:

- PostgreSQL — для хранения структурированных данных, информации о заказах, покупателях, товарах и других сущностях.
- Apache Hadoop HDFS — для распределённого хранения исходных и обработанных наборов данных.
- Apache Parquet — для хранения обработанных данных в колоночном формате, обеспечивающем эффективное выполнение аналитических запросов.
- Apache Hive — для организации табличного представления данных в распределённом хранилище и выполнения SQL-подобных запросов.
- Apache Kafka — для временного хранения и передачи потоковых событий между компонентами системы.

Предполагается организация хранения по принципу разделения исходных и обработанных данных. Исходные данные будут сохраняться в первоначальном виде, а результаты очистки, преобразования и объединения — в отдельных наборах данных. Такой подход позволит сохранять исходную информацию и при необходимости повторно выполнять обработку.

## б) Методы и средства сбора, предобработки и отображения данных

Сбор данных будет осуществляться несколькими способами в зависимости от типа источника.

Первоначальная загрузка исторических данных предполагается из файлов CSV и JSON. Для этого будут использоваться средства языка Python, включая библиотеки pandas и стандартные инструменты работы с файлами. При необходимости загрузка данных в реляционную базу будет осуществляться с использованием SQL и соответствующих библиотек подключения к PostgreSQL.

Для получения новых событий интернет-магазина предполагается использовать Apache Kafka. Например, информация о новых заказах, платежах и изменениях статусов заказов может передаваться в виде сообщений в соответствующие топики Kafka.

Перед аналитической обработкой необходимо выполнить предобработку информации. Она будет включать следующие операции:

- проверку структуры и типов данных;
- выявление и удаление дублирующихся записей;
- обработку пропущенных и некорректных значений;
- преобразование дат и числовых показателей к единым форматам;
- проверку согласованности идентификаторов связанных сущностей;
- объединение взаимосвязанных таблиц;
- нормализацию и преобразование отдельных атрибутов;

Для выполнения этих операций предполагается использовать Python, pandas и PySpark. При работе с большими объёмами информации основная обработка будет выполняться средствами Apache Spark, позволяющего распределять вычислительную нагрузку между несколькими узлами.

Результаты предобработки будут сохраняться в формате Parquet в распределённом хранилище.

Для отображения результатов предполагается использовать Apache Superset. С его помощью можно создавать интерактивные аналитические панели, содержащие графики, диаграммы и таблицы. Также возможно применение Apache Zeppelin для выполнения аналитических запросов и визуализации результатов непосредственно в среде интерактивных ноутбуков.

В рамках проекта планируется визуализировать динамику продаж, распределение заказов по категориям товаров, географию покупателей, среднюю стоимость заказов, оценки покупателей и показатели доставки.

## в) Технологии, методы и средства обработки данных

Основным инструментом распределённой обработки данных в проекте будет Apache Spark. Данная технология позволяет выполнять вычисления над большими наборами данных с использованием распределённых вычислительных ресурсов.

Для разработки приложения предполагается использовать язык Python и библиотеку PySpark.

В качестве основных средств обработки будут применяться:

- Apache Spark Core — для распределённой обработки данных;
- Spark SQL — для выполнения запросов и аналитических операций над структурированными данными;
- PySpark DataFrame API — для фильтрации, сортировки, группировки, объединения и преобразования наборов данных;
- Apache Hadoop HDFS — для хранения исходной и обработанной информации;
- Apache Kafka — для передачи и организации потоковых данных;
- Spark Structured Streaming — для обработки поступающих потоковых сообщений.

В рамках проекта предполагается реализовать несколько основных направлений обработки информации.

Первое направление — обработка данных о заказах и продажах. Будут выполняться объединение таблиц, группировка заказов по временным периодам, расчёт выручки, среднего чека, количества заказов и других показателей.

Второе направление — обработка информации о товарах и покупателях. Планируется определять наиболее востребованные категории товаров, анализировать частоту покупок, рассчитывать суммарные расходы покупателей и выявлять особенности потребительского поведения.

Отдельным направлением станет потоковая обработка событий с использованием Apache Kafka и Spark Structured Streaming. В рамках данного процесса будут реализованы преобразование поступающих сообщений, фильтрация некорректных записей и агрегирование информации за определённые временные интервалы.

Для хранения результатов обработки будут использоваться форматы Parquet и CSV, что позволит повторно использовать подготовленные данные в аналитических задачах и при построении моделей машинного обучения.

## г) Технологии и методы анализа данных, итоговые документы

Основная задача аналитической части проекта заключается в выявлении закономерностей, характеризующих деятельность интернет-магазина, потребительское поведение и динамику продаж.

Для анализа данных предполагается использовать методы статистического анализа, исследовательского анализа данных (EDA), агрегирования, группировки и сравнения показателей.

В качестве основных направлений аналитики выделяются следующие:

1. Анализ продаж. Предполагается исследовать динамику выручки и количества заказов, определять наиболее популярные категории товаров, анализировать изменения спроса во времени.
2. Анализ покупателей. Планируется исследовать частоту покупок, среднюю сумму расходов, повторные покупки и распределение клиентов по различным характеристикам.
3. Анализ качества обслуживания. Предполагается оценивать сроки доставки, количество отменённых заказов и взаимосвязь сроков доставки с оценками покупателей.
4. Анализ отзывов. Планируется исследовать пользовательские оценки и текстовые комментарии, выявлять наиболее распространённые положительные и отрицательные характеристики товаров и обслуживания.

Дополнительно предполагается применение методов машинного обучения с использованием Apache Spark MLlib и Spark ML.

В частности, планируется использовать:

- алгоритм K-Means для сегментации покупателей на основе показателей RFM (давность последней покупки, частота покупок и сумма расходов);
- TF-IDF и алгоритмы классификации, например Logistic Regression или Naive Bayes, для определения тональности текстовых отзывов;
- Random Forest Regression для прогнозирования количества заказов или других показателей спроса.

Качество моделей машинного обучения будет оцениваться с использованием соответствующих метрик. Для задачи классификации предполагается применять accuracy, precision, recall и F1-score, а для регрессионных моделей — MAE, RMSE и R².

Также планируется провести сравнительный анализ результатов, полученных с помощью традиционных методов обработки данных и алгоритмов машинного обучения. Это позволит определить, какие дополнительные закономерности удаётся выявить при использовании методов машинного обучения.

В результате выполнения проекта предполагается подготовить следующие документы и материалы:

1. Описание архитектуры аналитической системы и используемых источников данных.
2. Описание структуры хранилища и реализованных процессов загрузки данных.
3. Программный код приложения на Python/PySpark для обработки и анализа информации.
4. Результаты предобработки и аналитической обработки данных.
5. Описание применённых алгоритмов машинного обучения, результатов их обучения и оценки качества.
6. Результаты потоковой обработки данных с использованием Apache Kafka.
7. Итоговый аналитический отчёт с выводами и рекомендациями по результатам исследования.

## д) Реестр заинтересованных лиц и способы их информирования, собеседования и интервьюирования

В качестве основных заинтересованных лиц рассматриваются следующие группы:

1. Руководство интернет-магазина. Заинтересовано в получении обобщённой информации об эффективности деятельности предприятия, динамике продаж, выручке и перспективах развития. Для информирования предполагается использовать аналитические отчёты, презентации и демонстрацию интерактивных панелей.

2. Руководитель отдела продаж. Заинтересован в анализе объёмов продаж, востребованности товаров и изменении потребительского спроса. Основными средствами информирования будут регулярные отчёты, графики и дашборды.

3. Сотрудники отдела маркетинга. Заинтересованы в изучении потребительского поведения, сегментации покупателей и определении наиболее востребованных категорий товаров. Для выявления требований к аналитической системе предполагается проведение интервью и рабочих встреч.

4. Менеджеры по работе с клиентами. Заинтересованы в оценке удовлетворённости покупателей, анализе отзывов и выявлении проблем, возникающих при оформлении и доставке заказов. Для сбора требований предполагается проведение собеседований и анкетирования, а также анализ существующих обращений клиентов.


Для определения требований заинтересованных лиц к разрабатываемой системе предполагается использовать несколько методов взаимодействия.

Первый метод — индивидуальные интервью. Они позволят определить потребности отдельных категорий пользователей, выяснить, какие показатели необходимо анализировать и какие проблемы существуют в текущих процессах работы с данными.

Второй метод — анкетирование. С его помощью можно собрать мнения большого количества пользователей относительно удобства аналитических инструментов, востребованности отчётов и приоритетных направлений анализа.

Третий метод — подготовка технической и пользовательской документации. Она позволит заинтересованным лицам ознакомиться с архитектурой системы, основными функциями, результатами анализа и возможностями дальнейшего развития проекта.

## Заключение

В результате реализации проекта предполагается разработать прототип аналитической системы для обработки и анализа данных электронной коммерции с использованием технологий Apache Hadoop, Apache Spark и Apache Kafka.

Система позволит объединять информацию из различных источников, выполнять её предварительную обработку, осуществлять распределённые вычисления, применять методы статистического анализа и машинного обучения, а также обрабатывать потоковые события.

Практическая значимость проекта заключается в возможности использования полученных результатов для исследования потребительского поведения, повышения эффективности продаж, оценки качества обслуживания и прогнозирования спроса.

Разработанная архитектура может служить основой для дальнейшего масштабирования аналитической инфраструктуры интернет-магазина и внедрения технологий больших данных в реальные бизнес-процессы.
