# Проектирование алгоритмов MapReduce для обработки очень большого файла целых чисел

## 1. Общая характеристика задачи

Входные данные представляют собой очень большой файл целых чисел (ОБФЦЧ), объём которого может превышать доступную оперативную память одного компьютера. Для обработки такого файла используется модель MapReduce, позволяющая распределить вычисления между несколькими узлами кластера.

Входной файл разбивается на части, которые обрабатываются параллельно функциями Map. Результаты промежуточных вычислений объединяются функцией Reduce. Для решения поставленных задач используются операции преобразования данных, группировки по ключам и агрегирования значений.

Приведённые ниже фрагменты Python иллюстрируют логику Mapper и Reducer.

## 2. Алгоритм нахождения наибольшего числа

Задача заключается в определении максимального целого числа среди всех элементов входного файла.

**Функция Map:** 
- считывает целые числа из своей части файла; 
- определяет максимальное число в локальном фрагменте; 
- формирует пару
(ключ, значение), где ключ фиксированный, например `max`, а значение - локальный максимум.

**Функция Reduce:** 
- получает локальные максимумы от всех Mapper; 
- сравнивает полученные значения; 
- выбирает наибольшее из них.

Результатом работы алгоритма является максимальное целое число во
входном файле.

### Реализация на Python

``` python
def mapper_max(numbers):
    numbers = iter(numbers)
    try:
        local_max = next(numbers)
    except StopIteration:
        return

    for number in numbers:
        if number > local_max:
            local_max = number

    yield ("max", local_max)


def reducer_max(key, values):
    return max(values)
```

## 3. Алгоритм вычисления среднего арифметического

Для вычисления среднего арифметического необходимо определить сумму всех
чисел и их общее количество.

**Функция Map:** 
- считывает числа из локального фрагмента файла; 
- вычисляет локальную сумму чисел; 
- определяет количество чисел в
фрагменте; 
- формирует пару (ключ, значение), где ключ - фиксированный, например `avg`, а значение - пара (локальная сумма, локальное количество).

**Функция Reduce:** 
- суммирует все локальные суммы; 
- суммирует все
локальные количества; 
- вычисляет среднее арифметическое по формуле:

Среднее арифметическое = Общая сумма / Общее количество чисел.


### Реализация на Python

``` python
def mapper_average(numbers):
    total = 0
    count = 0

    for number in numbers:
        total += number
        count += 1

    if count:
        yield ("avg", (total, count))


def reducer_average(key, values):
    total_sum = 0
    total_count = 0

    for partial_sum, partial_count in values:
        total_sum += partial_sum
        total_count += partial_count

    if total_count == 0:
        return None  # файл не содержит чисел

    return total_sum / total_count
```

## 4. Алгоритм исключения дубликатов

Задача заключается в формировании набора чисел, в котором каждое число
встречается только один раз.

**Функция Map:** 
- считывает числа из локального фрагмента файла; 
- для каждого числа формирует пару (число, число), где ключом является само число.

**Функция Reduce:** 
- получает все значения, сгруппированные по ключу; 
- оставляет по одному экземпляру каждого ключа; 
- записывает уникальные
числа в выходной файл.

В результате формируется набор целых чисел без дубликатов.

### Реализация на Python

``` python
def mapper_unique(numbers):
    for number in numbers:
        yield (number, 1)


def reducer_unique(key, values):
    # Ключ — само число. Достаточно вывести ключ один раз.
    yield key
```

## 5. Алгоритм подсчёта количества различных целых чисел

Для подсчёта количества уникальных чисел используется предварительная
группировка по значениям.

**Первый этап Map:** 
- считывает числа из локального фрагмента файла; 
- для каждого числа формирует пару (число, 1).

**Первый этап Reduce:** 
- получает все значения, сгруппированные по
ключу; 
- определяет наличие каждого уникального ключа; 
- формирует промежуточную пару (число, 1), где единица означает, что данное число встретилось в наборе.

**Второй этап Map:** 
- получает пары (число, 1); 
- формирует пары (ключ, 1), где ключ фиксированный, например `count`.

**Второй этап Reduce:** 
- суммирует все единицы; 
- возвращает общее количество различных целых чисел.

Результатом является количество уникальных чисел во входном файле.

### Реализация на Python

``` python
def mapper_distinct_count(numbers):
    for number in numbers:
        yield (number, 1)


def reducer_distinct_count(key, values):
    # Каждому уникальному ключу соответствует одна единица.
    yield ("count", 1)


def mapper_count_after_dedup(items):
    # items — пары (уникальное_число, 1), полученные на первом Reduce.
    for _, value in items:
        yield ("count", value)


def reducer_total_count(key, values):
    return sum(values)
```

На первом этапе все одинаковые числа объединяются по ключу, поэтому
Reducer выдаёт одну запись для каждого уникального числа. На втором
этапе подсчитывается количество этих записей. В реальной системе второй
этап можно организовать как отдельную задачу MapReduce либо как
завершающее агрегирование результатов первого этапа.

## 6. Особенности хранения очень большого файла целых чисел

Очень большой файл целых чисел целесообразно хранить в распределённой
файловой системе, например HDFS (Hadoop Distributed File System). Такая
система позволяет размещать данные на нескольких узлах кластера,
обеспечивая масштабируемость и отказоустойчивость.

Основные особенности хранения:

-   Файл разделяется на блоки фиксированного размера, которые распределяются между узлами кластера.
-   Каждый блок хранится с несколькими копиями на разных узлах, что обеспечивает сохранность данных при отказе оборудования.
-   Обработка данных выполняется непосредственно на узлах, где расположены блоки файла, что уменьшает передачу данных по сети.
-   Файл может быть настолько большим, что не помещается в оперативную память одного компьютера, поэтому обработка выполняется последовательными порциями.
-   При добавлении новых узлов увеличивается общая ёмкость хранилища и
    вычислительная производительность системы.
-   Для эффективной обработки рекомендуется использовать текстовый формат с разделителями либо бинарный формат, позволяющий уменьшить объём хранения и ускорить чтение данных.

Таким образом, использование распределённой файловой системы и модели
MapReduce позволяет эффективно обрабатывать очень большие файлы целых
чисел, выполнять вычисления параллельно и обеспечивать устойчивость к
отказам отдельных узлов.
