# Консольное приложение аналитики e-commerce — ЛР 4 и ЛР 5

Приложение расширяет проект ЛР 4 и добавляет машинное обучение средствами Apache Spark MLlib.

## Состав проекта

```text
LR4_LR5/
├── main.py
├── requirements.txt
├── README.md
├── data/
│   └── очищенные Parquet-таблицы из ЛР 3
└── output/
    └── результаты аналитики, графики и ML-модель
```

## 1. Требования

- Python 3.10 или новее.
- Java 8/11/17, совместимая с установленной версией PySpark (для PySpark 3.5 рекомендуется Java 8/11/17).
- Очищенные Parquet-данные из ЛР 3.

Проверьте Python и Java:

```bash
python --version
java -version
```

Если Java не установлена, установите JDK и настройте переменную `JAVA_HOME`.

## 2. Размещение данных

Поместите в папку `data` Parquet-папки со следующими именами:

- `orders_clean.parquet`
- `order_items_clean.parquet`
- `products_clean.parquet`
- `customers_clean.parquet`
- `reviews_clean.parquet`

Каждая Parquet-папка должна содержать файлы данных `part-*.parquet` и служебные файлы Spark. Не нужно вручную переименовывать файлы внутри папок.

Если ваши каталоги из ЛР 3 называются иначе, измените словарь `FILES` в начале `main.py`.

## 3. Создание виртуального окружения и установка библиотек

Откройте терминал в каталоге проекта:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 4. Запуск

```bash
python main.py
```

Программа выводит меню. Введите номер операции и нажмите Enter.

## 5. Возможности ЛР 4

1. Просмотр структуры и количества строк в таблицах.
2. Анализ продаж по месяцам.
3. Анализ продаж по категориям товаров.
4. Подсчёт частоты слов в отзывах с помощью Spark RDD: `flatMap`, `reduceByKey`.
5. Анализ заказов по штатам покупателей.

## 6. Дополнительные возможности ЛР 5

Пункт 6 меню выполняет классификацию отзывов:

- объединяет отзывы, заказы и агрегированные товарные позиции по `order_id`;
- использует текст комментария и числовые характеристики заказа;
- считает оценки 1–2 отрицательными, 4–5 положительными; оценка 3 исключается;
- преобразует текст в признаки при помощи `RegexTokenizer`, `StopWordsRemover`, `CountVectorizer` и `IDF`;
- объединяет текстовые и числовые признаки через `VectorAssembler`;
- обучает Logistic Regression в составе Spark ML Pipeline;
- выводит Accuracy, F1-score, ROC-AUC и матрицу ошибок;
- сохраняет модель, предсказания и метрики в папку `output`.

Пункт 7 загружает сохранённую модель и выполняет предсказание на доступном наборе отзывов.

## 7. Результаты

После выполнения операций результаты сохраняются в `output`:

- графики в формате PNG;
- аналитические таблицы в CSV и Parquet;
- `sentiment_pipeline_model` — сохранённая Spark ML PipelineModel;
- `lr5_predictions` — предсказания тестовой выборки;
- `lr5_metrics_csv` — метрики модели.

При повторном обучении модель и соответствующие результаты перезаписываются.

## 8. Примечания

- Для ML-эксперимента необходим непустой текстовый столбец `review_comment_message`.
- Требуются столбцы `order_id`, `review_score` в таблице отзывов, `order_purchase_timestamp` в таблице заказов и `price` в таблице товарных позиций.
- Точность модели заранее не гарантируется и должна оцениваться по фактическим результатам запуска.
- Приложение работает в локальном режиме Spark (`local[*]`), поэтому для учебного запуска отдельный Hadoop-кластер не требуется.
