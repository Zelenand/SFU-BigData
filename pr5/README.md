## 1. Структура проекта

```text
LR5/
├── main.py
├── requirements.txt

└── data/
    ├── orders_clean/

```

## 2. Подготовка данных

Распакуйте очищенные данные из ЛР 3 в папке `data` (data.zip).

Приложение ожидает следующие имена Parquet-папок:

- `orders_clean`
- `order_items_clean`
- `products_clean`
- `customers_clean`
- `reviews_clean`


## 3. Установка зависимостей

**У вас должен быть установлен hadoop**
Откройте терминал в папке проекта.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

```bash
.venv\Scripts\activate
```

Установите библиотеки:

```bash
pip install -r requirements.txt
```

## 4. Запуск

```bash
python main.py
```

Программа выводит меню. Введите номер операции и нажмите Enter.

## 5. Дополнительные возможности ЛР 5

Пункт 7 меню выполняет классификацию отзывов:
- объединяет отзывы, заказы и агрегированные товарные позиции по `order_id`;
- использует текст комментария и числовые характеристики заказа;
- считает оценки 1–2 отрицательными, 4–5 положительными; оценка 3 исключается;
- преобразует текст в признаки при помощи `RegexTokenizer`, `StopWordsRemover`, `CountVectorizer` и `IDF`;
- объединяет текстовые и числовые признаки через `VectorAssembler`;
- обучает Logistic Regression в составе Spark ML Pipeline;
- выводит Accuracy, F1-score, ROC-AUC и матрицу ошибок;
- сохраняет модель, предсказания и метрики в папку `output`.

Пункт 8 загружает сохранённую модель и выполняет предсказание на доступном наборе отзывов.
