## Apache Hadoop. MapReduce. Apache Spark

Консольное приложение для аналитической обработки очищенных данных Olist, подготовленных в ЛР 3.
Отчёт по ходу работы находится в LR4_Olist_MapReduce_Spark.ipynb

## 1. Структура проекта

```text
LR4/
├── main.py
├── requirements.txt
├── README.md
└── data/
    ├── orders_clean/
    ├── order_items_clean/
    ├── products_clean/
    ├── customers_clean/
    └── reviews_clean/
```

## 2. Подготовка данных

Распакуйте очищенные данные из ЛР 3 в папке `data`.

Приложение ожидает следующие имена Parquet-папок:

- `orders_clean`
- `order_items_clean`
- `products_clean`
- `customers_clean`
- `reviews_clean`


## 3. Установка зависимостей

**У вас должен быть установлен hadoop**
Откройте терминал в папке проекта.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

```bash
.venv\Scripts\activate
```

Установите библиотеки:

```bash
pip install -r requirements.txt
```

## 4. Запуск

Выполните:

```bash
python main.py
```

После запуска приложение выводит меню. Введите номер нужного действия и нажмите Enter.

## 5. Возможности приложения

1. Просмотр количества строк и схем загруженных таблиц.
2. Анализ продаж по месяцам с построением графика.
3. Анализ выручки и количества проданных товаров по категориям.
4. MapReduce-подсчёт частоты слов в текстовых отзывах.
5. Анализ количества заказов по штатам покупателей.
6. Сохранение результатов в CSV и Parquet.

Графики и результаты экспорта сохраняются в папке `output`.
